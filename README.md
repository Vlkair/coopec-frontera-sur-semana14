# Taller 14 · Grupo 4 · COOPAC Frontera Sur

Paquete local de evidencias provisionales. La cartera se reconstruyó con la ficha 4 de la dinámica. Los campos OPEX vacíos de PF02 corresponden a proyectos postergados sin estimación. La norma del reporte se consigna como referencia del caso con alcance y plazo pendientes. Los pesos y la referencia presupuestal requieren validación en la entrevista simulada.

## Reproducción

Con Python 3.11 o posterior, pandas, matplotlib y networkx, ejecutar desde la raíz:

    python 07_portafolio/PR01_no_negociables.py
    python 07_portafolio/PR03_priorizacion.py
    python 07_portafolio/PR04_hoja_ruta.py
    python 07_portafolio/PR06_presupuesto.py

PR05 contiene meses relativos del plan. El año 3 incluye un hito de revisión. PR04 verifica los enlaces declarados y la capacidad de un proyecto por trimestre. Las dependencias técnicas requieren confirmación con el equipo.
